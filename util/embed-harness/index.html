Klicker Practice Quiz Embed Harness

Static parent page for verifying the embedded practice-quiz handshake. Load a quiz URL, send klicker:embed-init, inspect the latest payload, and keep a timestamped log of accepted and rejected messages.

The prefilled URL targets the local branch PWA on 127.0.0.1:3101. Production pwa.klicker.com rejects this localhost harness via CSP, so use the local stack for verification.

Controls

The harness auto-adds embed=true when missing so the iframe always runs in embedded mode. The URL is prefilled for the local verification stack, but the iframe only loads when you click Load iframe.
