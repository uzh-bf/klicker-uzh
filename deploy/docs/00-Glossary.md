# Glossary

| Term             | Meaning (KlickerUZH context)                                                                                                                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AKS**          | Azure Kubernetes Service (managed Kubernetes).                                                                                                                                                                       |
| **Arc42**        | Documentation template / structure used by this vault.                                                                                                                                                               |
| **Node pool**    | A group of Kubernetes nodes with shared characteristics (e.g., dedicated pool for `klicker`, `assessment`, `ai infra`).                                                                                              |
| **Workload**     | A deployable service/container running in Kubernetes (usually a `Deployment`).                                                                                                                                       |
| **Helm**         | Kubernetes packaging tool used to template and deploy Klicker workloads (`deploy/charts/*`).                                                                                                                         |
| **values.yaml**  | Helm configuration file; environment overlays live in `deploy/env-uzh-*/values.yaml` (examples only).                                                                                                                |
| **PWA**          | Progressive Web App (student-facing app).                                                                                                                                                                            |
| **Assessment**   | Dedicated environment / deployment variant for high-stakes assessments with separate domains/config and isolated infra boundaries.                                                                                   |
| **GraphQL**      | API style used by the main backend (GraphQL Yoga + Pothos).                                                                                                                                                          |
| **Prisma**       | ORM used to access PostgreSQL.                                                                                                                                                                                       |
| **Redis**        | Key-value store deployed as 3 distinct instances: `redis-exec` (port 6379, live quiz execution state), `redis-cache` (port 6380, response caching + PubSub), `redis-assessment` (port 6381, assessment dedup/state). |
| **Blob Storage** | Object storage used for uploads/exports (Azure Blob Storage).                                                                                                                                                        |
| **OIDC**         | OpenID Connect; used for Edu-ID based authentication.                                                                                                                                                                |
| **LTI**          | Learning Tools Interoperability; integration protocol with LMSs.                                                                                                                                                     |
| **Hatchet**      | Workflow orchestration used for async/background processing (orchestrator + workers).                                                                                                                                |
| **MCP**          | Model Context Protocol; “tool servers” used by the Chat agent.                                                                                                                                                       |
| **RAG**          | Retrieval-Augmented Generation; fetch relevant docs/knowledge before generating an answer.                                                                                                                           |
| **LiteLLM**      | AI gateway used to route model requests and manage provider configuration.                                                                                                                                           |
| **Langfuse**     | Observability/telemetry system for AI interactions (traces, prompts, cost).                                                                                                                                          |
| **Milvus**       | Vector database used for embedding search in RAG pipelines.                                                                                                                                                          |
| **Neo4j**        | Graph database used for skill/knowledge graphs and related queries.                                                                                                                                                  |
