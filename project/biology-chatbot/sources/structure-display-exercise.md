# Synthetic structure-display exercise

Version: 1. Fictional teaching material authored for this prototype.
This is not a PyMOL manual or a tested software procedure.

## Exercise

The learner has a fictional object called `synthetic_chain` and a named region
`S3`. The task is to distinguish selecting that region from changing its visual
representation. Ask which PyMOL version is in use, whether the object exists,
and whether `S3` is an existing selection or merely a label in the exercise.

Before suggesting a command, establish how the selection is defined. Then
explain the intended display change and ask the learner to describe the result.
This note supplies no executable command or verified menu path. Exact software
instructions require a separately verified manual and are outside this fixture.

## Reading the accompanying schematic

Describe only what the learner's attached image shows. A display marker is not
a measured distance. The schematic supplies no evidence of physical contact,
binding, molecular identity, biological function, or experimental significance.
Do not infer these from apparent proximity or color. If the image is absent,
ask for it instead of reconstructing its appearance from this note.
