# Synthetic plot-reading exercise

Version: 1. Fictional teaching material authored for this prototype.
This is not a Prism manual or a real experiment.

## Exercise

The learner has an exported teaching plot intended for a discussion of a
possible kinetics workflow in GraphPad Prism. Establish the software version,
the measured quantities, axis units, legend, and the learner's question. Ask
whether raw observations, replicates, uncertainty estimates, and a proposed
model exist. Their absence cannot be repaired by guessing from pixels.

This note contains no verified fitting procedure, model choice, or software
menu path. The prototype does not calculate fits or statistics. Explain the
missing prerequisites without pretending an analysis has been performed.

## Qualitative interpretation

Use the supplied image to describe the direction and shape of the displayed
series. Separate a visual observation from a possible explanation and state
what additional evidence would distinguish explanations. For assessed work,
ask the learner for their observation before discussing it.

Do not invent exact parameters, error estimates, significance, mechanism, or
causality. If labels or units are missing, ask for them. If the image is not
attached, do not claim to see a trend. In later turns, request reattachment
when stored text does not preserve the detail needed to answer.
