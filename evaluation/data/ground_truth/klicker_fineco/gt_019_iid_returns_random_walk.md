## I.I.D. Returns and a Random Walk

They are related, but they are not the same object. I.i.d. describes the return innovations: returns are independent over time and come from the same distribution. A random walk describes the price process generated by accumulating those unpredictable innovations, for example in logs:

$$
\ln P_t=\ln P_{t-1}+g_t
$$

where $g_t$ is the new log-return innovation. Thus i.i.d. returns can be an assumption behind a random-walk price model, but a return is not itself the price level.

If today's return innovation is independent of yesterday's, what information from yesterday could still help predict today's innovation?
