Besides live quizzes, KlickerUZH offers asynchronous learning activities. One of them is the **practice quiz**, which helps you **repeat** course content, for example before an exam. Lecturers create practice quizzes, and you can use them at any time. This section describes the **student view**; to create practice quizzes, see the [corresponding section](/tutorials/practice_quiz).

## Repetition and points

You can repeat a practice quiz as often as you like. Points are awarded only for the first attempt and for repetitions after a time interval set by the lecturer.

## Bookmarks and flagging

When you are signed in, you can bookmark important questions to build your own collection. If you spot a mistake in a question, use the flag to send feedback directly to the lecturer.

## Practice Pool

When you are signed in, the **Practice Pool** combines questions from all practice quizzes of the course. A round selects up to 25 question sets, and your earlier answers can influence the order. The individual practice quizzes stay available when you want to practise a particular topic.
