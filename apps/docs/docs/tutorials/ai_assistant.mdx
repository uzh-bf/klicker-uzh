## What is the KlickerUZH Assistant?

The KlickerUZH Assistant helps lecturers find existing content, prepare question drafts, and understand KlickerUZH features. Open **Assistant** in the bottom-right corner of the management application. On desktop, the chat opens beside your work and can be resized; on smaller screens, it opens as a full-screen panel.

:::info Beta feature
Enable the beta features available to your account in [User Settings](/getting_started/beta_features/). The assistant also requires AI access for your account. If its button is missing after enrollment, contact the KlickerUZH team.
:::

## What can I ask it to do?

- **Find reusable content:** "Find questions about diversification in my question pool."
- **Prepare a question:** "Draft a single-choice question about diversification with three answer options and feedback explaining each option."
- **Suggest feedback:** "Explain why this distractor is incorrect in one sentence." Review the suggested text and apply it yourself to an existing question.
- **Explain a feature:** "How do I set up a practice quiz?"

The assistant can search courses and elements accessible to your account and summarize a course. It uses the page you are working on as context, but does not gain additional permissions from that context. It cannot retrieve participant responses or results, or edit, publish, delete, duplicate, or share existing content.

## How do I save a generated question?

The assistant can propose **single choice**, **multiple choice**, and **free text** questions. To generate **KPRIM** elements or **flashcards** from course materials, use [AI element generation](/tutorials/ai_element_generation/).

1. Ask for a question. The assistant displays a proposal marked **Confirmation required**.
2. Check the question, answer options, correct answers or sample solutions, and feedback. Ask for revisions if needed.
3. Select **Create draft** to save it in your question library, or **Dismiss** to discard the proposal.
4. Open the saved draft in the library to review and edit it before using it in an activity.

Proposals are not saved automatically. If your access is read-only, the assistant can search and summarize but cannot save drafts.

## How do conversations and attachments work?

Use **Start a new conversation** to clear the current conversation; confirm the action if the conversation contains messages or unsent text. Closing and reopening the panel preserves the conversation while the page remains open, but reloading the page starts a fresh session.

You can attach up to two images per message, for example a diagram to discuss. Review the attachment feedback if a file cannot be accepted.

AI suggestions can contain mistakes. Verify the content and avoid entering personal information. For the chatbot used by students, see [Course Chatbot](/tutorials/chatbot/).
