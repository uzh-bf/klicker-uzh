# Direct Sharing & Access Requests

Direct sharing allows you to grant specific permissions for your resources (like Elements, Templates, Answer Collections, or Courses) to individual colleagues or predefined User Groups.

Key aspects include:

- **Initiating Sharing:**
  - Locating the 'Share' option for a specific resource (e.g., in the element library, course settings).
  - Understanding the sharing modal/interface.
- **Sharing with Individuals:**
  - Searching for users by name or email address.
  - Selecting the desired permission level (Read, Write, Execute, Admin - see Permissions & User Groups page).
  - Confirming the share action.
- **Sharing with User Groups:**
  - Selecting a User Group from a list or search.
  - Assigning the desired permission level to the entire group.
  - Understanding how group permissions interact with individual permissions (e.g., highest permission applies).
- **Viewing Existing Shares:**
  - How to see who currently has access to your resource and what level of permission they have.
- **Modifying/Revoking Access:**
  - Changing the permission level for a user or group.
  - Removing access for a user or group entirely.
- **Access Requests (If applicable):**
  - How users without access might request it (e.g., via a link or button).
  - Receiving notifications for access requests.
  - Reviewing requests and granting appropriate permissions or denying the request.
