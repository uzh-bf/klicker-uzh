---
title: Direct Sharing & Access Requests
---

Direct sharing gives colleagues access to teaching resources. Before sharing, decide which resources they need and whether they should be able to edit them. The [Answer Collections guide](/tutorials/answer_collections/) introduces reusable resources, and the [permission groups guide](/tutorials/permissions_groups/) explains how to think about access for a team. For help with the sharing options available to your account, use the support dialog in KlickerUZH Manage.
