## What can I generate?

AI-assisted creation turns course materials into **single choice**, **multiple choice**, **KPRIM**, or **flashcard** drafts. You review generated content before keeping elements in your library. Question generation also includes learning-design and question-plan approval stages.

:::info Upcoming AI feature
This guide describes a planned AI feature that is not yet included in the current v3 release. Enabling beta features alone does not make it available. The workflow below applies when the feature is deployed for your account.

Beta features are enabled by default. You can disable or re-enable them in [User Settings](/getting_started/beta_features/). This workflow also requires AI account access and a [knowledge base with a published graph](/tutorials/knowledge_bases/).
:::

## How do I start a generation?

1. Open **Generate Klicker elements** from a published knowledge graph.
2. Choose the **Element type**, the **Number of elements** from **1** to **20**, and the **Language**.
3. Select a **Difficulty** and at least one **Bloom level**. Bloom levels are a multi-select: **Remember**, **Understand**, **Apply**, **Analyze**, or **Evaluate**.
4. Optionally enter a **Focus topic**, add **Learning objectives**, and restrict the source pages when those controls are available for the selected element type.
5. Select **Generate elements**.

If the source shows **Update available**, its published graph is older than the current materials. You can use the existing version or rebuild the graph first to include the updates.

## Why does generation ask for approval?

For **single choice**, **multiple choice**, and **KPRIM**, generation pauses for your review at two stages:

- **Review the generation design:** Check the distribution across modules and learning objectives, including the evidence distribution.
- **Review the element plan:** Check the planned stems, difficulty, cognitive levels, and source coverage.

At each stage, select **Approve and continue** or **Reject generation**. If warnings are shown, review them and acknowledge them before continuing. The element plan is a draft: final titles and questions may be refined during generation while preserving the approved intent and evidence. Approving these stages allows generation to proceed; it does not save the final questions to your library.

**Flashcards** skip these two approval stages and proceed to generated-content review. If a flashcard generation produces fewer elements than requested, choose **Retry**, or acknowledge the incomplete set and select **Use generated elements**. These recovery actions are specific to flashcard generation.

## How do I review and save the results?

After approval, generation continues in the background. The generation page shows the current stage, the number of generated elements, and progress. You can leave the page and return when generation is complete.

In **Review generated elements**, use **Needs review**, **Needs attention**, **Kept**, and **Discarded** to find drafts at each stage.

1. **Open** a draft and compare its question, answer choices, marked correct answer or answers, feedback, explanation, learning design, and source citations with your course materials. Inspect its learning design and quality flags.
2. Edit the question, answers, or explanation as needed. Verify correctness and suitability for your students.
3. Select **Keep element** to save that element to your question library, or **Discard** to leave it out. A discarded draft can be restored for further review.
4. Use **Open saved element** to open the kept element in the **Library**.

Generated output is not added to the library automatically. Keep an element only after reviewing the generated answer and its sources. This workflow ends when the accepted element appears in the **Library**.
