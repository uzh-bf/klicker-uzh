# Activity Templates

Activity Templates allow lecturers to save the structure and content of a Live Quiz or a collection of elements as a reusable template. This facilitates the quick creation of new activities or the sharing of standardized question sets.

Key aspects include:

- **What is an Activity Template?**
  - Definition: A snapshot of a Live Quiz activity, including its elements (questions, content) and settings.
  - Purpose: Reuse successful quiz structures, share standardized content, streamline activity creation.
- **Creating Activity Templates:**

  - Naming and describing the template for easy identification.
- **Using Activity Templates:**

  - Importing elements from the library into a template.
