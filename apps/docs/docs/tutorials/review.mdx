---
title: Review Functionalities
---

Review functionalities on activities:

- Review functionality on activities, how it works (status incomplete, reviewed, changed after review)
- Review unsets when course assignment changes
- Review changes when activity or content is updated
- Review can be set for live quiz admins (if not in course) and course admins otherwise
- Designed for review workflows in larger courses between multiple lecturers / review of TA-created content

Batch operations on elements:

- Everything mentioned in tooltip on element list batch operations modal
- Only the elements visisble in the current list and selected from it can be edited through batch operations (describe step-by-step)
