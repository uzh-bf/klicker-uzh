---
title: Permissions & User Groups
---

Permission groups are used to manage colleagues’ access to teaching resources. They are distinct from [participant groups](/tutorials/participant_group_management/), which organize students for learning activities. When arranging shared access, agree on who needs to view, edit or administer the resources. For account-specific questions, use the support dialog in KlickerUZH Manage.
