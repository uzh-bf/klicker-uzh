## What are activity batch operations?

:::info
Activity batch operations allow you to make certain changes to a selection of activities at once. To modify multiple elements in a similar way, please navigate to the element list and use the [corresponding batch operation functionalities](/tutorials/element_batch_operations/).
:::

![Activity selection for batch operations](/img/review/activity_list_batch_operations.png)

Activity batch operations allow you to apply certain changes to a selection of activities at once. This includes assigning activities to courses, changing activity multipliers, adjusting scoring settings for live quizzes, and permanently deleting activities. This saves you the time to perform these actions individually through the standard editing interface for activities.

To execute any available batch operations, simply select the corresponding activities from the list using the checkbox next to them and click on the "Batch Operations" button at the top right. For a more detailed description of the available functionalities, refer to the tooltips in the application or the [following section](/tutorials/activity_batch_operations/#what-changes-can-be-applied-as-batch-operations).

## What changes can be applied as batch operations?

Once you have selected all activities you would like to modify using the batch operations functionality and opened the dialog, you will see all available operations and a list of your selected activities on the left side. Icons next to the activities in the list indicate if an activity is eligible for the selected operation. Please note that only draft and scheduled activities can be selected for batch operations, and only eligible activities will be changed or deleted. For more information on why a specific activity is not eligible, hover over the red icon. The following operations are available:

- **Multiplier Change:** Change the points multiplier that is applied for correct answers (correctness and bonus points for live quizzes and all points for asynchronous activities). Activity multipliers are always automatically combined with the multipliers defined on individual elements included in the activity. Since multiplier changes require the awarding of points, corresponding updates are only available for gamified activities or activities in assessment courses. When combined with a batch operation course assignment, the gamification and/or assessment settings of the newly assigned course apply.
- **Course Assignment:** Re-assign the selected activities to a new course from the dropdown menu (only non-archived and ongoing / future courses are available). Please note that if group activities are part of the selection, a course assignment change will only be applied to these if the newly assigned course has group formation enabled. Additionally, for activities with scheduled start and/or end dates (scheduled live quizzes / practice quizzes, all microlearnings and group activities), all dates need to lie within the course duration (between course start and end date). Selecting a non-gamified course for re-assignment will automatically block the modification of the multiplier setting.
- **Adjust scoring (Live Quiz only):** You can modify the grading logic for all selected live quizzes at once. Please note that the scoring adjustment functionality is only available for live quiz activities and will not affect other activity types. The operation allows you to adjust the following parameters (not including activity or element multipliers):
  - **Base Points:** Set the number of base points awarded for participation, regardless of answer correctness
  - **Correctness Points:** Configure points awarded for correct answers
  - **Bonus Points:** Set additional points that can be earned for fast and fully correct answers
  - **Bonus time:** Define the time window (in seconds) during which bonus points can be earned
- **Delete activities:** Permanently delete all eligible selected activities and their associated participant data and results. Deletion requires administrator or owner access to each activity and cannot be combined with another batch action. Assessment live quizzes additionally require administrator access to their assessment course. Before deletion starts, you must confirm that the action is irreversible. If an activity can no longer be deleted, for example because your permissions changed, other eligible deletions can still succeed and the application will report a partial result.
