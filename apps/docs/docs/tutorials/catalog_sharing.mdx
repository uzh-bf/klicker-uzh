---
title: Sharing via Catalog
---

Catalog sharing supports reuse of teaching resources beyond an individual collaboration. Check the resource description and the permissions offered before using or adapting material. For background on reusable question content, read the [Answer Collections guide](/tutorials/answer_collections/). If you need help accessing or contributing to a catalog, contact the team through the support dialog in KlickerUZH Manage.
