# Answer Collections

Answer Collections are reusable lists of predefined text items (e.g., diagnoses, symptoms, keywords, options). They serve as the source pool for answers in Selection (SE) and Case Study (CS) question types, ensuring consistency and saving time when creating questions that draw from the same set of potential answers.

Key aspects include:

- **What is an Answer Collection?**
  - Definition: A named, managed list of text-based answer items.
  - Purpose: Provide a standardized pool of options for SE and CS questions, avoid retyping, ensure consistency across questions.
- **Creating and Managing Answer Collections:**
  - Accessing the Answer Collection management area.
  - Creating a new collection: Naming and adding initial items.
  - Adding, editing, and removing items within a collection.
  - Deleting collections (consider impact on linked questions).
- **Using Answer Collections in Questions:**
  - **Selection (SE) Questions:** Linking a collection to an SE question, selecting the correct items from the linked list.
  - **Case Study (CS) Questions:** Linking a collection to define the "Items" that will be evaluated against the defined criteria in each case.
- **Benefits:**
  - Consistency: Ensures the same terminology/options are used across multiple questions.
  - Efficiency: Avoids repetitive typing of the same answer options.
  - Maintainability: Updating an item in the collection can propagate changes (if applicable) or simplifies finding where items are used.
