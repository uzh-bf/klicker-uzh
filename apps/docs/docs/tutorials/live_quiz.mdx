## What is a Live Quiz?

<!-- If a figure of this kind should be included, replace it with a more informative one -->
<!-- ![Live Quiz Evaluation](/img/live_quiz/lq_evaluation.png) -->

Live Quizzes in KlickerUZH involve real-time interaction during lectures to foster engagement between the lecturer and students. Multiple question blocks are activated at different intervals, allowing students to provide answers in real-time. Lecturers can view aggregated and anonymous student responses in the evaluation view.

To create a Live Quiz, navigate to the library and use the corresponding button at the top of the page. This opens the Live Quiz wizard, which will guide you through the process of creating a Live Quiz step by step. The different components and settings are explained in the following sections.

**Add the necessary metadata:**

1. **Name:** The name of the Live Quiz allows the user to distinguish the particular quiz from others. It is therefore not visible to students participating in the quiz. For recurring courses, we recommend adding information like the semester or lecture week to the name.
2. **Display Name:** The display name is shown to participants during the quiz execution.
3. **Description:** Optionally, a description can be added to the live quiz, which will be shown to participants at the beginning of the live quiz and before the first block is opened.

**Adjust the settings:**

4. **Course:** If desired, the Live Quiz can be assigned to a course. This is useful for organizing quizzes within a specific course context and allows KlickerUZH to directly display ongoing live quizzes to all participants of the course in the student app. Additionally, courses form the basis for the gamification framework in KlickerUZH (course leaderboard, course points, etc.) - more information can be found in the [gamification overview](/gamification/overview/). Live Quizzes without a course assignment or when assigned to a non-gamified course can be gamified nonetheless (also refer to the section on [gamified live quizzes](/tutorials/live_quiz/#what-functionalities-become-available-through-gamified-live-quizzes)). For all other cases, the course settings propagate to the quiz as indicated.
5. **Multiplier:** When gamification is enabled (separately or through the quiz being assigned to a gamified course), a multiplier can be set for the Live Quiz. The selected factor will be applied to all points (except for base points) collected in the Live Quiz and, if defined, combined with the multiplier of the question. For more information on the distributed points, please refer to the [grading logic overview](/gamification/grading_logic).
6. **Advanced Live Quiz Settings:** If desired, the different points distributed during a live quiz can be customized through the settings dialog that opens when clicking on the corresponding icon. Customized grading logic is only supported in gamified live quizzes. More information can be found in the [grading logic overview](/gamification/grading_logic).
7. **Audience Interaction:** You can already choose which audience interaction components should be enabled at the start of the Live Quiz. All settings can be modified at any time during the quiz execution.
8. **Response Collection:** By default, KlickerUZH keeps only anonymous, aggregated results. For research or teaching-evaluation use cases, you can enable correlated response storage for the new quiz. This stores each participant's first response per question and makes a pseudonymous CSV available after the quiz ends, with one respondent per row. The CSV never includes names, account identifiers, or response timestamps. Free-text responses are included verbatim, so do not ask participants to enter personal information.

**Create blocks using existing questions:**

9. In the final step, you can add your prepared questions to the Live Quiz using one of the following two methods. Questions in the same block will become available to students at the same time, while questions in different blocks will be released sequentially at the lecturer's discretion. If you need help with creating questions, please review the [tutorial on element management](/tutorials/element_management/).
   1. **Drag & Drop:** To add a new question to an existing block, simply drag the question onto the plus sign beneath the desired block. Similarly, you may also drag questions onto the "New block" button to create a new block with the question.
   2. **Select Questions:** Select one or more questions that should be added to the Live Quiz. The wizard will automatically display all different options for adding the selected questions to the activity. You can either add them to an existing block or create one or multiple new blocks with the selected questions.
   3. **Ordering:** To order individual elements within a certain block or move entire blocks (mainly for sequentially ordered practice quizzes), please use the provided arrows.
10. Optionally, you can add a **countdown** to the blocks, which will be displayed to the students during the quiz execution. Started blocks will be closed automatically after the countdown has expired.
11. Finally, confirm the creation and your Live Quiz is prepared!

Like all other activities in KlickerUZH, Live Quizzes can be edited as long as they are in their **draft** state. Once the quiz is started, its content can no longer be modified, since student submissions might be affected by the changes. The name and display name of the Live Quiz may be changed at any time, using the pencil icon next to the activity name.

To edit the content of a Live Quiz, open the actions dropdown and select the corresponding option. KlickerUZH will then automatically redirect you back to the library and open the familiar activity wizard already used during creation with all information pre-filled. After making any changes to the metadata of the quiz, its settings or the contained questions, **make sure to save your changes** in the last step of the wizard. For more information on how elements in a Live Quiz are updated and how to handle outdated elements, please refer to the [tutorial on element updates](/tutorials/element_updates_activities/).

All prepared Live Quizzes can be found in the activity list (menu entry "Activities"). Here you can edit your planned quizzes, delete unwanted activities, or start a Live Quiz. Once a Live Quiz is started, it can no longer be edited. Also note that once Live Quizzes are closed, they cannot be reopened, since they contain results submitted by all participating students that should not be overwritten, but can be duplicated to be executed again.

Once the Live Quiz has been started, the following actions can be performed on the **lecturer cockpit**:

1. **QR Code:** For students to be able to access your live quiz, you can display either a direct QR code for this particular quiz or a QR Code and link to all active live quizzes in your account (redirects to the active live quiz if there is only one). This information can also be accessed **ahead of the quiz execution** through the available actions on the activity list.
2. **Start first / next block:** In order for the participants to see the next set of questions, open the corresponding block by clicking the "Start first/next block" button. Once all students have answered, you can close the block at the same place. If a countdown is set for the block, it will automatically close when the countdown expires.
3. **Activate Feedback:** If the feedback option is activated, in addition to answering the question, participants also have the possibility to provide feedback on the speed and difficulty of the lecture. Their inputs will be displayed in aggregated form directly in the cockpit and are available as a timeline on the evaluation view after the quiz has ended. For more information, please refer to the [Live Q&A and Feedback tutorial](/tutorials/live_qa/).
4. **Activate Live Q&A:** If Live Q&A is activated, participants can ask follow-up questions they may have and provide written feedback. For more details on Live Q&A, review the dedicated [tutorial section](/tutorials/live_qa/).
5. **End / Abort Live Quiz:** Once the last block has finished, you can **end** the Live Quiz. Students will no longer be able to submit feedback or questions. The evaluation view of completed quizzes can be accessed through the activity list, and contains the final live quiz leaderboard, all submitted Live Q&A questions, as well as a timeline of all feedback in addition to the question evaluations. If you choose to **abort** your live quiz, please make sure to carefully review the mentioned consequences.

For a quiz with correlated response storage, the completed evaluation also offers a CSV download. Each row has a stable pseudonymous respondent number and each question execution has its own response column. Repeated downloads keep existing respondent numbers stable.

Additionally, you can access the following important views directly from the lecturer cockpit:

- **Audience View:** Access the view of your students for ongoing quizzes.
- **Lecturer View:** In large lecture settings, where teaching assistants can answer Live Q&A submissions, a filtered view of only pinned Live Q&A submissions and the aggregated feedback on speed and difficulty **is provided through the lecturer view**.
- **Evaluation:** On the lecturer cockpit, you can access the continuously updated evaluation view of the Live Quiz, allowing you to discuss incoming results, display correct answer options or the optionally defined explanation. For gamified Live Quizzes, the evaluation view also contains the leaderboard of the quiz.

For your students to be able to join your Live Quiz, they may use one of the following possibilities:

- **Direct QR Code:** Either through the lecturer cockpit (as described in the section on the [quiz execution](/tutorials/live_quiz/#how-can-i-execute-a-live-quiz)) or before starting the quiz through the corresponding action, you can access the direct QR code for the quiz under consideration. You may either project this code or include it in your slides for students to scan it with their mobile devices.
- **Account QR Code:** The same dialogs that contain the direct QR code also provide a QR code that displays a list of all currently running live quizzes in your account to students. If there is only one active live quiz, the QR code will redirect to this quiz. For courses with regular lectures we recommend using this QR code, as it does not require you to update it for each lecture.
- **Course Participation:** If you assigned all your Live Quizzes to a KlickerUZH course and your students joined this course, active quizzes will be automatically displayed to them on the home screen of the KlickerUZH student app.

KlickerUZH Live Quizzes are designed for execution in a synchronous lecture setting (in-person, hybrid or remote). By enabling gamification, you can enhance student engagement and motivation through various interactive elements. To create gamified live quizzes, you can choose one of the following options:

- Create a new **KlickerUZH course** for your lecture series and **enable gamification**. When assigning new live quizzes to this course, you should directly see that gamification will be enabled. Points collected during these quizzes will be transferred to the course leaderboard after the live quiz has ended.
- Assign your live quiz to a non-gamified course and **enable gamification separately**. Points collected during these quizzes will only be available on the leaderboard within the quiz context and will not be transferred to the course leaderboard.
- **Enable gamification on a Live Quiz without course assignment** by selecting the corresponding option. Similar to live quizzes in non-gamified courses, collected points will only be available in the context of this particular quiz.

After starting your gamified live quiz, you can provide your students with the corresponding access information as described in the [execution section](/tutorials/live_quiz/#how-can-i-execute-a-live-quiz). Live Quizzes assigned to a course can also be found directly on the home screen of the student application for logged-in participants of the course. Students can choose between the following options when participating in a gamified live quiz:

Additionally, we would like to provide you with the following recommendations for a successful implementation of gamification in Live Quizzes based on lecturer feedback:

- Lecturer encouragement: Motivational encouragement from the lecturer is crucial for fostering student participation in gamified challenges.
- Use countdowns: Set countdowns for your question blocks in the last step of the creation/editing process to limit the available time and motivate students by creating a playful environment.
- Try different question styles: Based on our experience, questions with a clear and not too easy answer work well. But we do encourage users to try different types of questions. For example, a guessing question with no obvious answer can activate students and make them engage more with the content.
