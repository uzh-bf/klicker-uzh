# Private Preview Features

Some features in KlickerUZH are initially released as "Private Preview" features. This means they are available for testing with selected users before being made generally available.

## What is Private Preview?

Private Preview is a phase in our feature deployment lifecycle where new functionality is tested with a limited audience before general release. This allows us to:

- Gather feedback from actual users in real-world scenarios
- Identify and address potential issues early
- Refine the user experience based on actual usage patterns
- Ensure stability before wide deployment

## Current Private Preview Features

The following features are currently available in Private Preview mode:

1. **Selection (SE) Questions** - Questions where students select from a predefined list of items (using Answer Collections)
2. **Case Study (CS) Questions** - Complex questions that enable students to evaluate multiple items against different criteria in the context of various scenarios
3. **Answer Collections** - Reusable lists of items that can be used across multiple questions and users
4. **Activity Templates** - Creating activities alongside the contained questions on a single page with pre-defined structural components and settings
5. **Sharing Functionalities** - Sharing functionalities for answer collections, all element types, activities, and courses between either individual users or user groups
