# Private Preview Features

Some features in KlickerUZH are initially released as "Private Preview" features. This means they are available for testing with selected users before being made generally available.

## What is Private Preview?

Private Preview is a phase in our feature deployment lifecycle where new functionality is tested with a limited audience before general release. This allows us to:

- Gather feedback from actual users in real-world scenarios
- Identify and address potential issues early
- Refine the user experience based on actual usage patterns
- Ensure stability before wide deployment

## Availability and access

Preview access depends on the feature and your account. See the [roadmap](/development/) for the current distinction between available capabilities, the upcoming v3.4 preview and planned work. The [Catalyst page](/catalyst/) explains how to request advanced access.

If a feature is described in a tutorial but is unavailable to you, use the support dialog in KlickerUZH Manage to ask about eligibility. Please do not assume that preview access includes every feature on the roadmap.
