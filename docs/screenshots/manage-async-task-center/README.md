These screenshots were captured from the real local Manage interface with a
synthetic lecturer profile and synthetic asynchronous task records. They do not
contain course, participant, or account data from a deployed environment.

  active knowledge-graph task at 1440×1000.
- `compact-populated-read.png` — the same task center after completed tasks
  were marked read at 1024×768; the active task remains in the badge count.
- `desktop-empty.png` — zero-task state and accessible empty-state copy at
