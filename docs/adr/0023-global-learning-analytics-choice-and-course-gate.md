# Global Learning Analytics choice with an independent course gate

Learning Analytics uses one explicit participant choice at account level, while
each course independently decides whether it offers Learning Analytics in the
same way it controls gamification: enabled by default, but switchable off and on
again by the course administrator. Data is eligible only when both the global
participant choice and the course gate allow it. The participant choice applies
prospectively; opting out deletes individual derived Learning Analytics data
and excludes future aggregates, without promising retroactive aggregate
recomputation or removal.

This replaces the earlier per-course participant-choice scope from the Learning
Analytics PR stack while retaining its fail-closed and de-identified output
principles.
