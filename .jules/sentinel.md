## 2023-10-27 - Insecure Random Number Generation\n**Vulnerability:** Weak random number generation using `Math.random()` in `generateRandomString` (auth utility).\n**Learning:** The legacy `Math.random()` method is not cryptographically secure and predictable, which could be exploited in auth/token contexts.\n**Prevention:** Use `crypto.getRandomValues()` (Web Crypto API) instead of `Math.random()` when generating auth strings or identifiers.
